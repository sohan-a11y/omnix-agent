# OMNIX Android AI Agent 📱

![GitHub License](https://img.shields.io/github/license/sohan-a11y/omnix-agent?style=flat-square)
![GitHub Last Commit](https://img.shields.io/github/last-commit/sohan-a11y/omnix-agent?style=flat-square)

[![Skills](https://skillicons.dev/icons?i=kotlin,android,java)](https://skillicons.dev)

On-device voice-controlled Android automation engine powered by Google Gemma inference and Android Accessibility Service UI controls.

---

## 🌟 Key Features

- 📱 **On-Device AI Inference**: Local Gemma model execution via MediaPipe LLM Inference engine.
- 🎙️ **Voice-Controlled Actions**: Hands-free voice recognition triggering UI tasks.
- ♿ **Accessibility UI Driver**: Automates clicks, text input, and app navigation natively.

---

## 🚀 Quick Start

```bash
git clone https://github.com/sohan-a11y/omnix-agent.git
cd omnix-agent
./gradlew assembleDebug
```
