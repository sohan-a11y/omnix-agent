OMNIX Android Agent: On-device voice-controlled Android automation engine powered by Gemma inference and accessibility UI controls.

---

## 🌟 Key Features

- 📱 **On-Device AI Inference**: Runs Google Gemma models locally via MediaPipe LLM Inference engine.
- 🎙️ **Voice-Activated Commands**: Hands-free voice recognition triggering complex device actions.
- ♿ **Accessibility Action Driver**: Automates app navigation, form filling, and system settings natively.
- 🔍 **APK Discovery Engine**: Dynamically inspects app capabilities and maps UI elements.

## 🚀 Quick Start

### Prerequisites
- Python 3.9+ / Node.js (depending on module)
- Git

### Installation
```bash
# Clone repository
git clone https://github.com/sohan-a11y/omnix-agent.git
cd omnix-agent

# Install dependencies (if python project)
pip install -r requirements.txt
```
